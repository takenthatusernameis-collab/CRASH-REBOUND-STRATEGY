## Project Summary

This repository implements the **crash-rebound strategy** per `crash-rebound-strategy.pdf` (Hyperliquid hourly perpetuals):
- **Primary trigger:** RSI(21) < 20 ("last day almost all selling")
- **Entry:** Next hourly open (spec-literal opt-in via `entry_spec_literal_next_open=True`)
- **Target:** +9% from entry (configurable via `target_pct`)
- **Stop:** 8× usual hourly range ratio (spec) over 14h lookback
- **Hedge:** ETH short on every leg, sized by vol ratio (336h lookback), capped 3×
- **Sizing:** 1.25% of coin's 24h USD volume (spec-compliant, fail-closed)
- **Gross cap:** 120% with equal-share cuts (never top-ups)
- **Rebound short:** Opens on +9% target fill, -9% target, 40% stop, 48h time exit

**Key implementation files:**
- `src/strategy/crash_rebound.py` — Signal generation, crash detection, rebound confirmation
- `src/strategy/config.py` — StrategyConfig with spec-compliant defaults & enforcement
- `src/strategy/risk.py` — RiskState, position sizing, gross-cap cuts, daily-loss halt
- `src/backtest/engine.py` — Hourly-bar execution (fees, funding, liquidation, slippage proxy)
- `scripts/run_portfolio.py` — Bar-by-bar multi-symbol portfolio simulation (no look-ahead)
- `scripts/run_campaign.py` — Fixture smoke test runner (explicitly NOT real evidence)
- `scripts/run_real_campaign.py` — Real-data campaign runner (Hyperliquid/OKX)

## Critical Architectural Decisions (Do Not Revert)

1. **Spec-literal entry is opt-in** (`entry_spec_literal_next_open=False` default). The PDF says "buy at next hourly open" with NO same-bar rebound candle. The canonical implementation additionally required `confirm_rebound()` which created a 0-trade funnel on real Hyperliquid data. The opt-in flag bypasses ONLY `confirm_rebound`; all other gates remain.

2. **RSI trigger IS the downtrend confirmation.** When `use_rsi_trigger=True`, the fast-MA `avoid_downtrend` filter is skipped (would nullify every legitimate RSI crash signal). This is enforced in `generate_signal`, `passes_universe_filter`, `filter_universe`.

3. **ETH hedge is fail-closed for spec-compliant paths.** `require_eth_hedge=True` in `backtest_simple` / `run_portfolio_simulation` raises `ValueError` if ETH data missing/insufficient. Default `False` preserves fixture/low-level callers.

4. **Volume-based sizing (1.25%) is NOT a free parameter.** `enforce_spec_position_size_pct()` rejects any value ≠ 1.25% when `enable_volume_based_sizing=True`. Disabled sizing (0) is the only escape hatch.

5. **Execution model is hourly-bar simplified.** The spec mandates 20s order slicing + L2 impact — this is explicitly NOT simulated. `execution_model="hourly_bar_simplified"`, `order_slicing_simulated=False`, `order_book_impact_model="slippage_proxy"` are documented limitations in every export.
